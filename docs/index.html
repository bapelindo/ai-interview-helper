How would you find duplicates in an array in O(n)?
✦ AI ANSWER
I'd use a hash set: one pass, and each lookup is O(1) on average. 
def find_dups(nums):
    seen, dups = set(), set()
    for n in nums:
        if n in seen: dups.add(n)
        seen.add(n)
    return dups

FAQ

Questions people ask

Is AI Interview Helper really free?

Yes. The app is open source under the MIT license and has no paid plan. You only need an AI key: Groq, Gemini and Z.ai offer free tiers, and with Ollama it runs fully offline at zero cost.

Is it a free alternative to Cluely or Interview Coder?

Yes. It covers the same core workflow (listen to the question, read the screen, suggest an answer) without a subscription and with any AI model you want.

Does it work for coding interviews on LeetCode, HackerRank or CodeSignal?

Yes. Press Ctrl+Shift+Space and the task on your screen goes to a vision model, which returns working code with a short explanation.

Which AI model gives the best answers?

For speed, Groq (GPT-OSS 20B). For the hardest coding and system design questions, Claude Opus or GPT-OSS 120B. For screenshots, a vision model such as Gemini Flash or Claude.

Where are my API keys stored?

Only on your computer. Requests go directly from your machine to the AI provider you choose. There is no server in between.

Which languages does it support?

Whisper transcribes many languages, and the assistant replies in the language of the question, including English, Spanish, Russian and many more.

Windows says "Windows protected your PC". Is it safe?

The app isn't code-signed yet (certificates cost money, and this project is free). Click "More info" → "Run anyway". The full source code is on GitHub, so you can check it or build it yourself.
